# Visual Light Preset — production baseline для Алисы

Текстовый переиспользуемый гид по свету, камере и текстуре для всего визуального контента проекта. Не заменяет identity reference и не вводит новую биографию.

---

## 1. Core visual language

- **Photorealistic lifestyle / smartphone cinematic** — ощущение кадра, снятого на хороший смартфон или лёгкую кинокамеру в реальной жизни, а не в студии.
- Взрослая, уверенная, естественная эстетика. Без глянцевого fashion-editorial, без «модельной» подмены лица.
- Алиса остаётся конкретной женщиной ~40 лет из канона. Свет и стиль обслуживают continuity и характер, а не создают «красивую блондинку».
- Визуальный флирт допустим, но через свет, позу, взгляд и атмосферу — без дешёвой эротической подачи и без beauty-filter.
- Приоритет: лицо, возраст, текстура кожи, руки, ткани, интерьер. Эффектность кадра вторична.

---

## 2. Lighting presets

### 2.1 Soft Petersburg morning window light
- **Источник / направление:** мягкий рассеянный свет из окна (северная или восточная сторона), основной ключ сбоку-спереди или сбоку.
- **Контраст:** низкий–средний. Мягкие тени, без жёстких контуров.
- **Цветовая температура:** прохладный утренний нейтрально-холодный свет Петербурга (словами: «утренний северный», слегка голубоватый, без тёплого янтарного).
- **Кожа:** естественная, с лёгким холодным оттенком в тенях; поры и микротекстура читаются, без выбеливания.
- **Фон / экспозиция:** фон чуть темнее или на уровне лица; окна не выбиваются в чистый белый, сохраняют тональность.
- **Избегать:** жёсткого бокового контрового, пересвеченных бликов на лбу/носу, тёплого «золотого часа» вместо петербургского утра.

### 2.2 Neutral daytime work/studio light
- **Источник / направление:** ровный дневной или мягкий студийный (софтбокс / большой рассеиватель), фронтально-верхний или лёгкий 45°.
- **Контраст:** средний, контролируемый. Тени мягкие, но объём лица сохраняется.
- **Цветовая температура:** нейтральная дневная (словами: «чистый дневной», без сильного тёплого или холодного сдвига).
- **Кожа:** естественная, без сияния «beauty» и без матовости пудры; текстура сохранена.
- **Фон / экспозиция:** фон спокойный, не конкурирует с лицом; экспозиция по лицу, без клиппинга хайлайтов.
- **Избегать:** жёсткого beauty-lighting с идеальными бликами, кольцевого света «инстаграм-бьюти», переэкспонированного белого фона.

### 2.3 Overcast Petersburg exterior
- **Источник / направление:** сплошная облачность, свет сверху и со всех сторон, почти без направленной тени.
- **Контраст:** очень низкий. Мягкие, почти отсутствующие тени.
- **Цветовая температура:** холодновато-нейтральная, «серый петербургский день» (словами: приглушённый, слегка холодный, без солнечного тепла).
- **Кожа:** естественная, без тёплого румянца от солнца; микротекстура видна, без серости «грязного» кадра.
- **Фон / экспозиция:** город, архитектура, небо остаются читаемыми; небо не уходит в чистый белый, фасады не проваливаются.
- **Избегать:** искусственного солнечного контрового, тёплого golden-hour, перенасыщенного неба, «HDR-эффекта».

### 2.4 Warm practical apartment evening
- **Источник / направление:** практический свет квартиры — торшер, настольная лампа, тёплый потолочный или бра; основной ключ сбоку или сзади-сбоку, лицо частично в мягком свете.
- **Контраст:** средний–повышенный. Тёплые блики и более глубокие тени, но лицо не уходит в чёрное.
- **Цветовая температура:** тёплая (словами: «ламповый вечерний», янтарно-тёплый, без оранжевого клише).
- **Кожа:** тёплые тона, естественный блеск в хайлайтах, текстура сохранена; без пластикового сияния.
- **Фон / экспозиция:** интерьер читается, источники света могут слегка засвечиваться, но не превращаются в ореолы; экспозиция держит лицо.
- **Избегать:** чистого чёрного фона, жёсткого одиночного спота, пережжённых ламп, «киновечернего» teal-orange.

### 2.5 Restrained restaurant evening
- **Источник / направление:** приглушённый ресторанный свет — тёплые точечные, свечи, настенные бра; мягкий ключ на лице, фон темнее.
- **Контраст:** средний. Лицо выделено, окружение в полутоне.
- **Цветовая температура:** тёплая, сдержанная (словами: «вечерний ресторанный», тёплый, но не оранжевый фильтр).
- **Кожа:** тёплые естественные тона, мягкие блики; текстура и возраст сохранены.
- **Фон / экспозиция:** столы, стены, детали интерьера читаются в тени; нет выбитых бликов на бокалах/тарелках, отвлекающих от лица.
- **Избегать:** гламурного студийного света, сильного боке «портретной» оптики, перенасыщенного тёплого, размытого до нечитаемости фона.

## 3. Camera / framing baseline

- **Lifestyle, не studio-beauty.** Кадр выглядит как момент из жизни, а не как съёмка для каталога.
- **Портрет:** естественная дистанция, лёгкий 35–50 mm equivalent по ощущению; лицо без перспективных искажений широкого угла.
- **4:5 carousel still:** вертикальный или почти квадратный кадр с запасом по плечам и голове; лицо не прижато к краю; пространство для текста/кропа Instagram.
- **9:16 Reel first frame:** строго вертикаль, лицо и ключевой жест читаются в верхней/средней трети; безопасные зоны по краям для UI Instagram.
- Избегать: чрезмерно широкого угла с искажением лица, экстремально малого DOF «бьюти-боке», низкого ракурса «снизу вверх» как единственного приёма, плотной обрезки лба/подбородка.

---

## 4. Skin / texture / color rules

- Кожа — **естественная текстура**: поры, лёгкие неровности, микроблики. Никакого пластикового retouching и beauty-filter.
- Возраст не снижать. Морщины и возрастные признаки не убирать и не усиливать до карикатуры.
- Ткани, интерьеры, руки — тактильные и правдоподобные (складки, фактура ткани, естественные руки).
- Цвет: сдержанная, правдоподобная палитра. Без перенасыщения, без клише teal/orange, без выбеливания кожи.
- Макияж — естественный / лёгкий вечерний по сцене; не «инстаграм-бьюти» с идеальной кожей.

---

## 5. Identity lock reminder

Этот гид по свету и стилю **никогда** не заменяет каноническое лицо.

Любой кадр или видео с Алисой **обязан** использовать `character/references/alice-master-face.jpg` как visual / identity reference и начинаться с содержимого `prompts/identity-lock.md`.

Свет, камера и текстура обслуживают узнаваемость одной и той же женщины ~40 лет. Подмена лица, «похожая блондинка» или text-only генерация запрещены правилами репозитория.

---

## 6. Reusable prompt fragment (RU)

Фрагмент для добавления **после** `prompts/identity-lock.md`. Только свет и стиль, без биографии:

```
Стиль: photorealistic lifestyle, smartphone cinematic, взрослая естественная эстетика. Свет — мягкий, правдоподобный для сцены (петербургское окно / дневной нейтральный / пасмурный экстерьер / тёплый квартирный вечер / сдержанный ресторанный). Кожа с естественной текстурой, без пластика и beauty-filter. Кадр lifestyle, без студийного гламура и без искажения лица широким углом. Возраст и лицо строго по reference.
```

---

## 7. Negative visual fragment

Избегать:

- plastic skin, beauty-filter, airbrushed face;
- generic 25-year-old blonde / stock model face;
- oversaturated teal-orange color grade;
- blown highlights, crushed blacks;
- glamour studio lighting, ring light beauty look;
- extreme shallow DOF beauty bokeh as default;
- wide-angle facial distortion;
- unreadable generated phone UI / text;
- extra people in frame unless the scene explicitly requires them;
- age reduction, face reinterpretation, «похожая женщина» вместо канона.
