## Неприкосновенные параметры

1. Текущий канон: `character/references/alice-master-face-v2.jpg`
   (пока файл не залит в repo — использовать still `IMG_5732.jpg` / chat id `JW6HK`).
2. Архив лица: `character/references/alice-master-face.jpg` (v1, close-up с wrap-платьем). Не удалять.
3. Нельзя создавать «похожую» женщину вместо Алисы.
4. Нельзя менять форму лица, глаза, нос, губы, линию челюсти.
5. Возраст около 40. Не омолаживать до 25–30.
6. Волосы: блонд. Укладка может меняться, лицо — нет.
7. Кожа реалистичная, без пластикового beauty-filter.
